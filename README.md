# 💰 AI Financial Data Analyst

An AI-powered financial data analysis chatbot built with **Python, Pandas, Groq, and Streamlit**.

Users can upload a financial CSV file and ask questions about their data using natural language.


Here is the live application: (https://financial-chatbot-p155.onrender.com/)

## 🚀 Features

- Upload financial CSV files
- Natural-language financial queries
- Dataset-aware question answering
- Pandas-powered calculations
- Groq LLM for query understanding and explanations
- Automatic company/entity validation
- Statistical summary
- Data quality analysis
- Missing-value detection
- Financial rankings
- Comparisons
- Trend analysis
- Automatic Plotly visualizations
- Chat history
- Dataset preview

## 🧠 Architecture

User Question
↓
Groq Query Planner
↓
Query Validation
↓
Pandas Analysis
↓
Verified Result
↓
Groq Explanation
↓
Streamlit Response + Visualization

## 🛠️ Tech Stack

- Python
- Pandas
- Streamlit
- Groq API
- Plotly
- python-dotenv
